# Glossario assembleare M07.1

| Termine | Significato nel software |
|---|---|
| Assemblea | Aggregato di convocazioni, agenda, partecipanti e rappresentanze di un condominio |
| Sessione | Prima o seconda convocazione, con esito e presenze indipendenti |
| Punto ODG | Voce numerata con eventuale UUID di una versione di bilancio o esercizio |
| Potenziale avente diritto | Soggetto con titolarità storica efficace, da verificare per materia |
| Rappresentante unitario | Scelta operativa preparatoria; evita duplicazione della quota dell'unità |
| Snapshot partecipanti | Situazione anagrafica e millesimale congelata a una data esplicita |
| Revisione | Copia immutabile dell'intero stato operativo dopo una modifica autorizzata |
| Convocazione destinatario | Recapito e canale congelati per uno specifico soggetto e snapshot |
| Evento dichiarato | Invio/consegna registrato manualmente, senza prova verificata implicita |
| Delega verificata | Delega controllata manualmente da StudioAdmin; non sostituisce verifiche normative |
| Presenza per delega | Titolare rappresentato da un delegato verificato per unità specifiche |
| Assenza dichiarata | Evento esplicito con motivo; non coincide con mancata registrazione |
| Totale informativo | Conteggio operativo di presenti/quote, senza attestazione di quorum |
