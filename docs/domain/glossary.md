# Glossario essenziale
| Termine | Significato |
| --- | --- |
| Studio / Tenant | Ambito isolato di uno studio amministrativo. |
| Condominio | Edificio o complesso amministrato, appartenente a uno studio. |
| Fabbricato / scala | Articolazione facoltativa di un condominio. |
| Unità immobiliare | Bene fisico distinto dalle persone che lo possiedono. |
| Soggetto / Person | Persona fisica o giuridica, indicata per ora da un nome visualizzato. |
| Periodo di proprietà | Legame soggetto–unità con quota frazionaria e date di validità. |
| Tabella millesimale | Insieme nominato di quote di un condominio. |
| Quota millesimale | Valore relativo a unità e tabella, con date di validità. |
| Esercizio / AccountingPeriod | Intervallo amministrativo; non implica movimenti o chiusura contabile. |
| Audit | CreatedAt e UpdatedAt UTC, applicati dalla persistenza. |

Validità: estremi inclusivi, fine assente = aperta. Le quote di comproprietà
possono coesistere; controlli aggregati e sovrapposizioni saranno definiti con
requisiti successivi. Nessuna regola contabile è implicita nel glossario.
