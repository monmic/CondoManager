# Glossario deliberativo M07.2

| Termine | Significato |
|---|---|
| Criterio versionato | Finalità, chiamata, materia, soglie esatte, basi, validità, fonte e ambito revisionati |
| Soglia razionale | Frazione intera confrontata con prodotti incrociati, senza arrotondamento |
| Testa / centro di voto | Titolarità distinta rappresentata, con una o più unità; non equivale al delegato fisico |
| Building | Valore nominale dell'intero edificio, distinto dalla somma delle quote ammesse |
| Eligible | Tutte le teste/quote ammesse per materia, inclusi assenti |
| Present | Ammessi presenti/rappresentati all'istante congelato, anche astenuti e non votanti |
| Expressed | Favorevoli e contrari; esclude astensioni e mancata espressione |
| Quorum costitutivo | Valutazione distinta per sessione/istante, con Satisfied/NotSatisfied/Undetermined |
| Platea congelata | Fonte immutabile di teste, unità, valori e rappresentanze utilizzabile da uno specifico voto |
| Ballot | Scelta per una testa, con soggetto rappresentato ed esprimente derivati lato server |
| NonVoting | Presente senza voto espresso, distinto da Abstained e Absent |
| Undetermined | Dati/criterio non consentono un esito certo; non equivale ad approvazione |
| Delibera consolidata | Esito e testo immutabili, con voto, regola, fonti, data e attore |
| Rettifica testuale | Nuova versione riferita all'originale, con stesso voto/esito e motivo |
| Applicazione M06 | Comando esplicito che richiama i servizi amministrativi, senza produrre rate o scritture |
| Collegamento storico | Riferimento a bilancio già approvato senza cambiare data o approvazione originaria |
| Conclusione | Chiusura amministrativa dell'assemblea con checklist e snapshot, senza PDF |
